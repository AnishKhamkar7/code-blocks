# Next.js starter

A standalone Next.js App Router starter with TypeScript and ESLint. It is independent of the Turborepo stack collection.

## Start a project

```sh
npm install
npm run dev
```

Open `http://localhost:3000`. Edit `src/app/page.tsx` to begin building.

## Commands

- `npm run dev`: start the development server
- `npm run build`: create a production build
- `npm start`: run the production build
- `npm run lint`: check ESLint rules
- `npm run typecheck`: check TypeScript types

Requires Node.js 20.9 or newer.
