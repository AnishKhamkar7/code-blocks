# Turborepo + Express + Next.js + S3

A pnpm Turborepo starter for an S3 file vault, with an Express API, Next.js client, Prisma, Redis, and AWS S3/STS integrations.

Install dependencies with `pnpm install`, then use `pnpm dev` to run the apps. Configure the required database, Redis, and AWS environment values in `.env` before starting the server.
