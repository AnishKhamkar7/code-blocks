# Code blocks

A collection of reusable code and project starters.

## Turborepo starters

- [`turborepo/hono-vite-auth`](./turborepo/hono-vite-auth): Hono, React/Vite, Better Auth, Prisma/PostgreSQL, TanStack Router and Query.
- [`turborepo/express-vite-auth`](./turborepo/express-vite-auth): Express, React/Vite, Better Auth, Prisma/PostgreSQL, TanStack Router and Query.
- [`turborepo/express-nextjs-auth`](./turborepo/express-nextjs-auth): Express, Next.js App Router, Better Auth and Prisma/PostgreSQL.

## Standalone starters

- [`nextjs`](./nextjs): a minimal Next.js App Router setup with TypeScript and ESLint, outside the Turborepo collection.
