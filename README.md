## 🚀 How to Use

1. Browse to the category you need (e.g., `frontend/components` or `backend/auth`).
2. Copy the snippet or boilerplate into your project.
3. Adjust configuration (environment variables, project-specific logic) as needed.
---

## 🔖 Categories

### 🌐 Frontend

- **components/** → Reusable UI (buttons, modals, forms, etc.)
- **styling/** → CSS, Tailwind, theme configs
- **state-management/** → Redux, Zustand, Context API setups
- **hooks/** → Custom React hooks (useDebounce, useAuth, etc.)
- **utils/** → Helpers for frontend apps

### ⚙️ Backend

- **auth/** → JWT, OAuth, session strategies
- **file-uploads/** → Multer, Cloudinary, S3 integrations
- **database/** → Prisma, Mongoose, raw SQL snippets
- **apis/** → REST/GraphQL controllers and services
- **validation/** → Schema validation with Zod, Joi, Yup
- **testing/** → Jest, Supertest, Mocha setups
- **utils/** → Logging, error handling, cron jobs

### 🛠 Deployment

- **docker/** → Dockerfiles, docker-compose configs
- **ci-cd/** → GitHub Actions, GitLab CI pipelines
- **configs/** → Nginx, PM2, server setup files

### 📑 Docs

- API documentation templates
- Swagger/OpenAPI setups

## 📌 Goal

This repo serves as a **developer toolbox** for quickly bootstrapping projects by reusing common code blocks, reducing repetitive work, and ensuring consistency across apps.

## 🧑‍💻 Contribution (for personal use or team)

- Add new code blocks inside the relevant category.
